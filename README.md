# avionics-intro-activity
This is for our first activity in avionics, which focuses on using basic git functions

First, open up a text editor(like notepad), and write "Hello World" into the file, then save the file.
*Name the file "[your name] hello world", and the .txt type should already be selected

Now, back on the repo, under the code tab, and go to the add files button, before clicking upload files. This will let you create a pull request

Take your text file from earlier, and upload it to the repo, then commit the changes on a new branch.
*Name your branch "[your name]-patch-1", which should also be the automatically generated name on github
