# avionics-intro-activity
This is for our first activity in avionics, which focuses on using basic git functions

First, open up a text editor(like notepad), and write "Hello World" into the file, then save the file.
*Name the file "[your name] hello world", and the .txt type should already be selected

Now, back on the repo, under the code tab, and go to the add files button, before clicking upload files. This will let you create a pull request

Take your text file from earlier, and upload it to the repo, then commit the changes on a new branch.
*Name your branch "[your name]-patch-1", which should also be the automatically generated name on github.

This will open up a new window to name your pull request, name it with your name, then click "Create Pull Request"

Now go find a partner who has done all the above, click on the pull requests tab, and find your pull request, and click on it.

On the right, there will be a tab that says "reviewers". Add a reviewer, and enter in your partner's name. Now they an review your commit!

Go back to the pull requests tab, and find the request with your partner's name. They should've let you review their additons!

It should say that they requested for you to make a review, click on the yellow button, and finalize your approval!
*remember to select "approve" in the dropdown, so you actually approve their commit

Once your partner approves your code, go to the code tab. You should see the text file you made at the beginning in the repository, with the text "hello world" inside.

This mirrors the workflow for git. when you have a change, make the change, create a pull request, get someone to review your change, and then it will be committed to the main repo!
